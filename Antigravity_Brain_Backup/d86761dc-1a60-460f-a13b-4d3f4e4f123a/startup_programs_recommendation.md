# 시작 프로그램 비활성화 추천 목록

현재 남아있는 시작 프로그램 중, 컴퓨터 부팅 속도 향상과 자원 절약을 위해 **추가로 끌 만한 항목**들을 정리했습니다.

## 🚀 비활성화 강력 추천 (필요할 때만 켜도 되는 프로그램)

이 프로그램들은 윈도우 시작 시 굳이 켜질 필요가 없으며, 필요할 때 직접 실행하는 것이 좋습니다.

| 프로그램명 | 용도 | 비활성화 추천 이유 |
| :--- | :--- | :--- |
| **LM Studio** | 로컬 AI 모델 구동 | AI 모델을 항상 돌리는 것이 아니라면, 실행 시 자원(메모리/GPU) 소모가 커서 꺼두는 것을 권장합니다. |
| **Microsoft Copilot** | 윈도우 AI 비서 | 평소에 사용 빈도가 낮다면 백그라운드 자원만 소모하므로 끄는 것이 좋습니다. |
| **Brother iPSMonitor** | 프린터 상태 모니터링 | 인쇄할 때만 작동해도 문제없으므로 시작 시 켤 필요는 없습니다. |

## ☁️ 선택적 비활성화 (클라우드 및 메신저)

사용 패턴에 따라 자동 실행 여부를 결정하세요.

| 프로그램명 | 용도 | 조언 |
| :--- | :--- | :--- |
| **OneDrive** | MS 클라우드 동기화 | 실시간 파일 동기화가 필요 없다면 끄고, 가끔 수동 실행해도 됩니다. |
| **NAVER MYBOX** | 네이버 클라우드 | 마찬가지로 실시간 동기화가 필수가 아니라면 꺼두는 것이 좋습니다. |
| **KakaoTalk** | 카카오톡 PC 버전 | 부팅 즉시 카톡 알림을 받고 싶지 않다면 해제하세요. |

## 🛡️ 유지 권장 (건드리지 않는 것이 좋은 프로그램)

시스템 안정성과 보안을 위해 켜두어야 합니다.

- **SecurityHealth** (Windows 보안)
- **MaximAudioSvc** (오디오 드라이버 관련 서비스)
