	개인적/실험적 목적으로만 사용해 주십시오.
	설치 방법
	선호하는 Python 패키지 관리자(uv, pip, pipx 등)를 사용하여 PyPI에서
	notebooklm-mcp-server
	를 설치할 수 있습니다.
	소스 코드에서 직접 설치하는 방법도 지원합니다.
	업데이트 방법
	[121] (262,206)<a aria-label='Permalink: 업데이트 방법' class='anchor' href='#업데이트-방법' id='user-content-업데이트-방법' />
	패키지 관리자의 업그레이드 명령어를 사용하여 최신 버전으로 업데이트하세요.
	업데이트 후에는 AI 도구를 재시작하여 연결을 갱신해야 합니다:
	Claude Code:
	애플리케이션을 재시작하거나 재연결 명령을 사용
	Cursor:
	애플리케이션 재시작
	Gemini CLI:
	CLI 세션 재시작
	제거 방법
	[122] (262,473)<a aria-label='Permalink: 제거 방법' class='anchor' href='#제거-방법' id='user-content-제거-방법' />
	MCP를 완전히 제거하려면 패키지 관리자의 제거 명령어를 사용하세요. 선택적으로 캐시된 인증 토큰이나 AI 도구의 설정 파일에서도 제거할 수 있습니다.
	인증
	[123] (262,588)<a aria-label='Permalink: 인증' class='anchor' href='#인증' id='user-content-인증' />
	MCP를 사용하기 전에 NotebookLM 인증이 필요합니다.
	자동 모드
	를 권장합니다. 전용 Chrome 프로필을 실행하여 구글에 로그인하면 쿠키가 자동으로 추출됩니다. 로그인 정보는 추후 인증 갱신을 위해 저장됩니다.
	만약 자동 모드가 작동하지 않는다면,
	파일 모드
	를 통해 Chrome 개발자 도구에서 수동으로 쿠키를 추출하여 저장할 수 있습니다.
	인증 성공 후에는 MCP를 AI 도구에 추가하고 재시작하세요.
	자세한 내용과 문제 해결 방법은 **
