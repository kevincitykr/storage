주요 내용 및 기능
시각적 디자인-코드 전환:
Stitch에서 자연어로 생성한 웹 디자인을 Antigravity IDE와 같은 환경으로 가져와 실제 작동하는 코드로 구현합니다.
MCP 브리지 구성:
Stitch API 키를 사용하여 Antigravity IDE 내에서 MCP 서버를 구성, 에이전트가 디자인 DNA를 직접 가져오게 합니다.
자동화된 워크플로우:
디자인 토큰을 수동으로 내보낼 필요 없이, AI 에이전트가 디자인 토큰과 레이아웃 메타데이터를 기반으로 React/Tailwind 코드를 스캐폴딩하고 생성합니다.
실시간 수정 및 반영:
생성된 코드와 원본 Stitch 디자인을 비교하며 버튼 패딩, 글꼴 두께 등 시각적 요소를 AI를 통해 즉시 수정할 수 있습니다.
