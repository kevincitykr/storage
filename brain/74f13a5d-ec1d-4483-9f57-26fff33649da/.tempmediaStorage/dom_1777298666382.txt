	[26] (485,514)<a class='Link--secondary' href='/wonseokjung/connect-ai/commit/f2311c6aba617396c631f151e29e3060db511a67' title='fix(2.12.5): bridge server failures now surface instead of going silent

http.createServer + server.listen reports failures via the 'error' event,
not via throw — so the prior try/catch could not catch EADDRINUSE or
permission errors. The bridge then silently never bound port 4825 and
external tools (EZER / A.U Training) saw net::ERR_FAILED with zero
indication on the IDE side.

Now:
- server.on('error') emits a vscode error toast with a specific message
  (EADDRINUSE → "포트 이미 사용 중, 재시작 필요"; other → raw error).
- server.listen success path posts a 4-second status-bar confirmation
  "🟢 Connect AI Bridge: 포트 4825 listening" so the user can verify
  the bridge is up at IDE startup.
