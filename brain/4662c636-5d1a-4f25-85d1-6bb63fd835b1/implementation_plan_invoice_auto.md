# 발송대기 송장입력 자동화 구현 계획

현재 `ali_master_final.py`와 `ali_tracking_monitor.py`가 뼈대만 있는 상태입니다. 이를 완성하여 알리익스프레스에서 송장을 가져와 샵마인 데이터와 매칭하고 업로드 파일을 만드는 과정을 자동화합니다.

## 1. 알리익스프레스 송장 수집 (ali_tracking_monitor.py 개선)
- **대상 페이지**: `https://trade.aliexpress.com/orderList.htm?filterName=waitConfirm` (배송 중)
- **수집 항목**:
    - 알리 주문번호 (Order ID)
    - 송장번호 (Tracking Number)
    - 택배사 (Logistics Provider)
    - 수취인명 (Masked)
    - 주소 (Partial/Masked)
- **상세 로직**: 
    - 주문 목록에서 'Track Order' 버튼 또는 상세 페이지 링크를 클릭하여 정확한 송장 번호를 추출합니다.
    - 여러 계정(sessions/*.json)을 순회하며 데이터를 통합 수집합니다.

## 2. 샵마인 데이터 매칭 (ali_master_final.py 핵심 로직)
- **데이터 로드**: `발송대기_필터링결과.xlsx` 또는 최신 샵마인 엑셀 파일을 읽어옵니다.
- **매칭 알고리즘**:
    - **1단계 (이름 매칭)**: 샵마인 '수령자'와 알리 'Masked Recipient' 비교 (예: `홍길동` vs `홍*동`)
    - **2단계 (주소 매칭)**: 주소의 핵심 키워드(동/번지/아파트명)가 포함되어 있는지 확인
    - **3단계 (전화번호)**: 알리 상세 페이지에서 전화번호 끝자리를 볼 수 있는 경우 추가 검증
- **결과 생성**: 매칭 성공 시 `송장번호`와 `택배사`를 채웁니다.

## 3. 샵마인 업로드 파일 생성
- 샵마인에서 [송장입력] 메뉴에 업로드 가능한 양식으로 저장합니다.
- 파일명 예: `shopmine_invoice_upload_YYYYMMDD.xlsx`

## 4. 실행 및 검증
- `ali_session_manager.py`를 통해 세션이 최신인지 확인.
- `ali_master_final.py` 실행 후 생성된 엑셀 파일을 샵마인에 업로드.
