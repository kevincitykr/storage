# 알리익스프레스 수집 자동화 작업 표준 (Work Standard v1.0)

이 문서는 모든 컴퓨터에서 알리익스프레스 수집 작업을 수행할 때 준수해야 할 기술적 기준과 운영 규칙을 정의합니다.

## 1. 수집 상품 우선순위 및 필터링 규칙
1.  **한국 발송 최우선:** 모든 수집은 한국에서 발송되는 상품(K-Venue 또는 국내 셀러)을 최우선으로 합니다.
2.  **자동 필터링:** 
    *   K-Venue 전용 페이지 활용: `tabId` 파라미터를 사용하여 세부 카테고리별로 접근합니다.
    *   일반 카테고리 수집 시: URL에 반드시 `shpf_co=KR` 또는 `shipFromCountry=KR` 파라미터를 포함하여 중국 배송 상품을 필터링합니다.
3.  **금지어 필터:** `forbidden_master_list.json`에 정의된 금지어(브랜드, 품목 등)가 포함된 상품은 자동으로 건너뜁니다.

## 2. 봇 운영 및 순환 규칙
1.  **카테고리 순환 (Auto-Rotation):**
    *   단일 페이지에서 '새 상품 없음'이 연속 10회 발생할 경우, 해당 리스트가 소진된 것으로 간주합니다.
    *   이 경우 봇은 자동으로 다음 `tabId` 또는 다음 지정 카테고리로 전환하여 수집의 연속성을 유지합니다.
2.  **중복 방지:** 
    *   `collected_master.json` 파일을 통해 이미 수집된 상품 URL을 관리하며, 중복 수집을 원천 차단합니다.
3.  **대기 시간 준수:** 알리익스프레스의 차단을 방지하기 위해 상품 상세 페이지 방문 사이에는 12~18초의 랜덤 대기 시간을 유지합니다.

## 3. 로그 및 보고 표준
1.  **명확한 상태 출력:** 터미널에는 항상 [현재 카테고리], [분석 중인 상품 수], [기수집/금지어 제외 수]가 실시간으로 표시되어야 합니다.
2.  **예외 상황 보고:** 페이지 로드 실패, 캡차 발생, 카테고리 자동 전환 등의 이벤트 발생 시 명확한 [INFO]/[WARN] 로그를 남깁니다.

## 4. 코드 및 데이터 관리
1.  **공통 파일 구조:** 
    *   수집 프로그램: `final_sourcing_bot.py`
    *   수집 기록: `collected_master.json`
    *   금지어 목록: `forbidden_master_list.json` (상위 디렉토리 공통 관리)
2.  **업데이트 알림:** 봇 로직 변경 시 반드시 버전 정보를 업데이트하고 사용자에게 변경 사항을 보고합니다.
