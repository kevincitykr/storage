# 작업 목록
- [ ] 견적 초기화로 인한 부품 재등록 (i7-14700, MSI B760M) - 진행 중
- [ ] DDR5 64GB (32GB x 2) 추가
- [ ] RTX 4060 Ti 16GB 추가
- [ ] 1TB NVMe SSD 추가
- [ ] 품절 및 호환성 오류 확인
- [ ] (필요시) 다나와에서 재고 및 견적 확인
- [ ] 최종 결과 보고 (재고가 있는 호환 부품 리스트)

# 발견된 사항
- 사이트 세션이 불안정하여 견적 목록이 계속 초기화되는 현상 발생.
- 상단 검색창 대신 카테고리 내 검색창을 사용하려 했으나 '총 0건'으로 검색 결과가 나오지 않음.
- '전체' 필터를 선택한 후 다시 i7-14700 검색 시도 예정.
- 사이트가 매우 불안정하므로 재시도가 여러 번 필요할 수 있음.
