## 3. FAQ & 기술 지원

### Q1. "얘들이 결과를 낼 능력이 되나?"
**A.** 네, 충분히 가능합니다! 현재 구축된 환경(Connect AI)은 초급자를 위한 교육 콘텐츠와 실습 자료를 배포하기에 최적화되어 있습니다. 제가 생성한 템플릿을 기반으로 콘텐츠만 채워 넣으면 훌륭한 결과물이 완성됩니다.

### Q2. "깃허브는 왜 못하냐?" (GitHub Sync 실패 문제)
**A.** 터미널에서 직접 확인한 결과, **로컬 Git은 원격 저장소와 정상적으로 통신하고 있습니다.**
*   **원인 추정:** `Connect AI` 확장 프로그램 내부 설정에서 GitHub 인증 토큰(Personal Access Token)이 누락되었거나 권한이 부족하여 동기화에 실패했을 가능성이 높습니다.
*   **해결 방법:** 
    1.  VS Code 설정에서 `Connect AI` 관련 GitHub Token 설정을 확인해 주세요.
    2.  Private 저장소라면 `repo` 권한이 있는 토큰이 필요합니다.
