# 등장인물 설정 (Character Sheet)

- **직업**: (표면상) 베트남 박닌 중소기업 자재 관리 부장 / (실체) 전직 국정원 블랙 요원 '코드네임: 곰(Bear)'

- **특이사항**: 베트남어 못하는 척하지만 다 알아듣음. 도구 없이 볼펜 하나로 제압 가능.
