# 📺 레오 — 영상 기획 및 제작

## 분석 및 평가

**1. 데이터 수집:**

- 데이터 수집 과정이 명확하고, 사용된 도구가 적합합니다.
- 관련 데이터는 정확하고 최근 자료임이 확인됩니다.

**2. 분석 방법:**

- 분석 방법은 통계적 분석보다는 주관적 분석으로 구성되어 있습니다.
- 분석 결과는 명확하고 이해하기 쉽습니다.

**3. 결과:**

- 영상 분석 데이터를 기반으로 유튜브 트렌드 분석 보고서와 경쟁사 영상 분석 및 트렌드 연구 보고서가 작성되었습니다.
- 새로운 콘텐츠 아이디어도 발굴되었습니다.

**4. 제언:**

- 주관적 분석 방법은 연구 결과의 신뢰도를 낮출 수 있습니다.
- 더 정확하고 통계적으로 유용한 분석 방법을 사용할 수 있습니다.

**5. 향상점:**

- 연구 결과를 활용하여 영상 제작 계획을 수립할 수 있습니다.
- 분석 과정에 데이터 분석 전문성을 더 활용할 수 있습니다.
