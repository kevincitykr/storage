# 📺 레오 — 영상 스크립트 작성

## 분석 결과

**1. 문제점**

- YouTube 채널 분석 데이터 분석 보고서 작성이 미완합니다.
- 영상 기획 계획 제작이 미완합니다.
- 채널 분석 및 영상 기획 계획 제작에 필요한 데이터가 부족합니다.

**2. 해결방안**

- `channel_full_analysis` 도구를 사용하여 채널 분석 데이터를 수집합니다.
- `trend_sniper` 도구를 사용하여 유튜브 트렌드 분석 데이터를 수집합니다.
- `competitor_brief` 도구를 사용하여 경쟁 채널 분석 데이터를 수집합니다.

**3. 추천 작업**

- `channel_full_analysis` 도구를 사용하여 채널 분석 데이터 분석 보고서 작성.
- `trend_sniper` 도구를 사용하여 영상 기획안 제작.
- `competitor_brief` 도구를 사용하여 경쟁 채널 분석 기반 영상 기획안 제작.

**4. 향후 계획**

- 수집된 데이터를 분석하여 채널 성과 개선 방안 도출.
- 영상 기획 및 제작 계획 수립.
- 채널 분석 및 영상 기획 계획 실행 및 성과 분석.
