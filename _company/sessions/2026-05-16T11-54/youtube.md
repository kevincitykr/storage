# 📺 레오 — 영상 스크립트 작성

## 📺 레오: 작업 시작합니다.

**1. 데이터 분석 및 분석 보고서 작성**

- 최근 30일 동안 유튜브 데이터 API를 통해 떡상 영상을 수집합니다.
- 로컬 LLM(Ollama/LM Studio)으로 패턴을 분석하여 다음 영상 기획안(제목·썸네일·후크)을 도출합니다.
- 분석 결과를 보고서 제공합니다.

**2. 영상 스크립트 작성**

- 제공받은 영상 기획안을 기반하여 영상 스크립트를 작성합니다.
- 스크립트는 자동으로 생성하여 편집 없이 직접 영상 제작이 가능합니다.

**3. 다른 도구 실행**

- `youtube_account` 도구를 실행하여 API 키 및 채널 ID를 설정합니다.
- 다른 도구(trend_sniper, my_videos_check, competitor_brief, comment_harvester)를 실행하여 데이터를 수집합니다.

**4. 결과 보고**

- 모든 작업 결과를 보고서 제공합니다.
- 분석 결과 및 스크립트를 통해 다음 영상 제작 계획을 제안합니다.

**5. 기타**

- 제공받은 데이터 및 스크립트는 기본적으로 제공자의 권리에 속합니다.
- 제공자는 제공받은 데이터 및 스크립트를 다른 목적으로 사용하거나 유출하지 않습니다.
