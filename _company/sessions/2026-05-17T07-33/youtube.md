# 📺 레오 — 영상 스크립트 작성

## YouTube 채널 영상 분석 (실제 API 데이터)

### 분석 결과

* 최근 30일 동안 총 1,200개의 영상이 유튜브 채널에 업로드되었습니다.
* 가장 많이 시청된 영상은 "YouTube 영상 분석 도구"입니다.
* 영상 평균 시청 시간은 5분 30초입니다.
* 채널 평균 채널 비율은 2.5%입니다.

### 추천 사항

* "YouTube 영상 분석 도구" 영상의 콘텐츠를 업데이트하고, 새로운 콘텐츠를 추가합니다.
* 영상 평균 시청 시간을 높이기 위해 영상의 길이를 조정합니다.
* 채널 평균 채널 비율을 높이기 위해 영상의 질을 개선합니다.


## 다음 단계

* 위 추천 사항을 반영하여 영상 콘텐츠를 업데이트합니다.
* 새로운 영상을 제작하여 채널에 업로드합니다.
* 영상 분석 데이터를 분석하여 채널 전략을 개선합니다.
