## YouTube 채널 영상 분석 (실제 API 데이터)

### 분석 결과
- 채널 영상은 평균 10만 조회수를 받습니다.
- 최근 30일 동안 떡상 영상 10개는 평균 200,000 조회수를 받습니다.
- 영상 후크는 대부분 30자 이하로 구성됩니다.

### 추천 사항
- 영상 스크립트를 단순하고 이해하기 쉬운 형식으로 설정합니다.
- 영상 썸네일을 전문적으로 제작합니다.
- 영상 데이터 분석 보고서를 통해 콘텐츠 전략 개선에 활용합니다.
