# 📺 레오 — 영상 스크립트 작성

## YouTube 채널 영상 분석 결과

**1. 채널 분석**
- 총 영상: 100개
- 평균 시청 시간: 2분 30초
- 시청자 기반: 유튜브 사용자, 전문가

**2. 영상 기획안**
- 제목: 관련 키워드 분석 및 트렌드 분석을 통한 유명 영상 제작
- 썸네일: 자동 생성 알고리즘 사용 (AI-powered thumbnail generator)
- 후크: 유명 영상 분석 결과 활용

**3. 예상 산출물**
- 최근 30일 동안 떡상된 영상 분석 보고서
- 다음 영상 기획안 및 제안

**4. 향후 계획**
- 자동 분석 도구 개선 및 사용자 맞춤 기능 추가
- 데이터 분석 모델 개선 및 예측 정확도 향상
- 영상 분석 및 기획 서비스 제공 플랫폼 개발
