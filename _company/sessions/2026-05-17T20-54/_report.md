**오류 메시지:** `UnicodeEncodeError: 'cp949' codec can't encode character '\u274c' in position 2: illegal multibyte sequence`

**문제 해결:** `youtube_account` 도구의 설정 파일(youtube_account.json)에 API 키와 채널 ID를 정확히 입력해야 합니다.

**다음 단계:**
- `youtube_account.json` 파일을 확인하여 API 키와 채널 ID를 확인합니다.
- `youtube_account.py` 도구를 실행합니다.
- 결과를 확인하여 문제 해결 여부를 확인합니다.
