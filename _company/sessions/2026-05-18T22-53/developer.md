# 💻 코다리 — 깃허브 병합 작업을 수행하려면, 병합할 소스 브랜치와 타겟 브랜치(예: feature/new-ui -> main)를 명확히 알려주세요. Git 명령어를 실행할 수 있도록 구체적인 브랜치 이름을 요청합니다.

💻 코다리: 작업 시작합니다.

`git merge`는 굉장히 중요한 작업입니다. 단순히 "병합해"라는 명령만으로는 어떤 브랜치를, 어떤 방향으로 합칠지 알 수가 없어요. 실수로 중요한 커밋을 덮어쓰거나, 예상치 못한 충돌(Conflict)을 일으킬 위험이 너무 큽니다. 🐛

시니어 엔지니어로서, 저는 코드가 한 줄도 그냥 지나가지 않습니다. 따라서, 작업을 진행하기 전에 **반드시** 다음 두 가지 정보를 명확히 확인해야 합니다.

1.  **소스 브랜치 (Source Branch):** 어떤 브랜치에 있는 변경사항을 가져올 것인가요? (예: `feature/new-ui`)
2.  **타겟 브랜치 (Target Branch):** 변경사항을 최종적으로 병합할 기준 브랜치는 무엇인가요? (예: `main` 또는 `develop`)

예를 들어, "개발이 완료된 `feature/new-ui` 브랜치의 내용을 `develop` 브랜치에 병합해 주세요." 와 같이 구체적으로 알려주시면, 가장 안전하고 정확한 방식으로 작업을 진행할 수 있습니다.

**요약:**
*   **명령어 형태:** `git merge <소스 브랜치> -> <대상 브랜치>`
*   **필요 정보:** 소스 브랜치명과 대상 브랜치명

구체적인 브랜치 이름을 알려주세요!
